# Teorema de Pitágoras APP

Aplicación educativa interactiva en español para aprender el Teorema de Pitágoras desde cero.

## Funciones

- Ingreso de longitudes de los lados de un triángulo.
- Verificación automática de triángulos rectángulos.
- Explicación paso a paso del cálculo.
- Ejercicios prácticos con retroalimentación cuando la respuesta es correcta o incorrecta.
- Vista 3D interactiva con rotación, zoom y cuadrados de área.
- Configuración lista para publicar en Netlify.

## Publicación en Netlify

Esta app es estática. En Netlify usa:

- Build command: vacío
- Publish directory: `.`
